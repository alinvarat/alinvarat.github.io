hi, i’m linwrath.

I founded PULSE and build every part of it myself.

I design the boards, write the Arduino libraries, print the parts and write the Thai manuals myself. Then I build them in batches of about ten and sell them to students, teachers and schools.

When a robot misbehaves I would rather simulate it than guess, which is how LineSim started. The same habit of testing before trusting runs through TradeLab.

from board to track

How one of my robots gets made.

  1. 01boardschematic and layout in KiCad
  2. 02bodyparts modelled in FreeCAD, then printed
  3. 03firmwarean Arduino library for the sensors and motors
  4. 04tunePID tuned in LineSim before the real track
  5. 05trackrecord a lap, then replay it
per-stage replay, PulseMini V2.2

150segments

Speed and PID stored for each stretch of track, in 1,016 of the board’s 1,024 bytes of EEPROM.

linesim sensor table

2.43million points

Light samples the GPU prepares per track, so sensor reads during tuning come from a table.
